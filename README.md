# Charlton Brown home

This is the website of Charlton Brown, an architecture firm based in North London. It is a staticly generated by [Next.js](https://nextjs.org/) (a [React](https://reactjs.org/) framework) connecting to [DatoCMS](https://www.datocms.com/) via GraphQL for content management. It’s hosted on [Vercel](http://vercel.com/) and is deploys are triggered automatically when any changes are merged with the `main` branch.

# Local setup

## Prerequisites

- Node.js installed locally, I recommend at least v.14
- A membership to the CharltonBrown organisation on GitHub
- A membership to the CharltonBrown organisation on Vercel

## Install steps

1. Clone the repo `git clone git@github.com:CharltonBrown/charltonbrown.git`
2. Once within the repo you’ll need some env vars to set the API keys to connect with DatoCMS

- Install the Vercel CLI `npm i -g vercel`
- Authenicate with `vercel login`
- Pull the environment variables `vercel env pull`

3. Install the project dependencies with `npm i`
4. Run the project `npm run dev`

# Broken Dato builds

If you have made changes to an existing Dato block at the same time as carrying out work on feature branch (i.e. changing block a field name), it may lead to a broken builds on the `main` branch as we only have one Dato environment currently. It most cases, this should resolve when the feature branch is merged.
